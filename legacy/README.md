# Legacy compatibility layer

هذه الملفات هي النسخة القديمة من Wasl v6. تبقى مؤقتًا للتوافق والرجوع الآمن، ولا يجوز أن تكون مصدر الحقيقة لتطبيق v1.1.

- لا يقرأ Backend v1 أي بيانات من `app_state` أو `user_profiles`.
- لا تُحذف هذه الملفات قبل إتمام ترحيل البيانات واختبارات القبول.
- المسارات القديمة تحت `/api/*` ستبقى محولات توافق حتى اعتماد القطع النهائي.
