# شعارات وَصْل المحلية

الأصول الرسمية المستخدمة في شاشة الدخول والطباعة:

- `vision.png` — شعار رؤية السعودية 2030.
- `hospital.png` — شعار مستشفى الملك فيصل بمكة.
- `makkah.png` — الشعار الثالث المرفق للمشروع.

المسارات في `public/index.html` نسبية إلى مجلد `public` وتستخدم `assets/logos/*.png`. يمكن تحديث الملفات مع الحفاظ على الأسماء دون تعديل الكود. توجد معالجة `onerror` حتى لا تتعطل شاشة الدخول أو الطباعة مؤقتاً عند تعذر تحميل ملف.
