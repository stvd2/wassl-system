# شعارات وَصْل المحلية

تُستخدم هذه الأصول محلياً في شاشة الدخول والطباعة عبر المسارات:

- `vision.svg` — شعار الرؤية.
- `hospital.svg` — شعار المستشفى.
- `makkah.svg` — شعار تجمع مكة.

يمكن استبدال ملفات SVG الحالية بالملفات الرسمية مع الحفاظ على الأسماء، دون تعديل الكود. الملفات الحالية رسومات احتياطية محلية مؤقتة وليست بديلاً عن ملفات الهوية الرسمية إذا توفرت.
