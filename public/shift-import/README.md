# استيراد المناوبات المحلي

مكوّن تحليل للمعاينة فقط؛ لا يُعدّل `DATA`، ولا يحفظ، ولا يرفع محتوى الملفات إلى أي خادم. يُقرأ الملف داخل المتصفح. لا توجد واجهة مستخدم أو زر استيراد مدمجان؛ يربط التطبيق المكوّن بشاشة المعاينة والتأكيد بنفسه.

## التحميل والاستعمال

على الصفحة المضيفة تحميل المكتبتين المحليتين بالترتيب، وتقديم مجلد `shift-import` وملفاته كما هو من نفس المنشأ:

```html
<script src="/shift-import/vendor/xlsx.full.min.js"></script>
<script src="/shift-import/shift-import.js"></script>
```

```js
// file هو File من input، وDATA.users هي قائمة المستخدمين الحالية.
const result = await window.WaslShiftImport.parse(file, DATA.users);
// عرض result.errors وresult.warnings، ثم result.rows للمعاينة.
// كل بيانات الملف غير موثوقة: عند بناء العرض استخدم textContent أو esc، لا innerHTML مباشرة.
const canProposeImport = result.errors.length === 0 && result.rows.length > 0 &&
  result.rows.every(row => row.status === 'ready');
// لا يحصل أي حفظ تلقائي. اطلب تأكيدًا صريحًا بعد المعاينة وإعادة التحقق.
```

تحميل PDF.js يحدث عند اختيار PDF فقط من `vendor/pdf.min.mjs`، ويعمل الـworker من `vendor/pdf.worker.min.mjs`؛ لا يوجد CDN وقت التشغيل. ينبغي إتاحة `.mjs` بنوع MIME صالح لجافاسكربت والسماح في CSP بتحميل وحدات وworker من المنشأ نفسه (`script-src 'self'` و`worker-src 'self'`، أو ما يعادلها في سياسة التطبيق). اختُبر عبر HTTP محلي، لا تفترض عمل وحدات المتصفح عند فتح `file://` مباشرة.

## شكل النتيجة

تعيد `parse(file, users)` وعدًا بـ:

```js
{
  rows: [{
    date: '2026-11-25',           // YYYY-MM-DD أو null عند عدم اليقين
    shift: 'صباحي',              // صباحي / مسائي / ليلي أو null
    user_id: '...',              // معرّف التطبيق الأصلي أو null
    user_name: '...',            // اسم الحساب عند مطابقته؛ وإلا الاسم الوارد
    role: 'doctor',              // coordinator / doctor / beds / admin أو null
    notes: '',
    source: { sheet: 'Sheet1', row: 2 }, // أو {page: 1, row: 2} في PDF
    raw: { date: '...', shift: '...', user_name: '...' },
    status: 'ready',             // أو needs_review
    ambiguous: false,
    errors: [],                 // رسائل عربية للصف
    candidates: [],             // حسابات متطابقة عند الالتباس فقط؛ لا تتضمن أسرارًا
    date_candidates: []         // بدائل التاريخ الرقمي الملتبس
  }],
  errors: [],                    // [{message, source?}]؛ أخطاء ملف/جدول
  warnings: []                   // [{message, source?}]
}
```

رقم `row` في CSV رقم السجل المنطقي، وفي PDF رقم السطر النصي المُستخرج داخل الصفحة، لا رقمًا مضمونًا لصف الجدول الأصلي. قد توجد `rows` رغم وجود خطأ على مستوى جدول آخر؛ **لا تُجرِ استيرادًا مع `result.errors` غير الفارغة**. الأخطاء القاتلة تقطع المعالجة وتحذف النتائج الجزئية. مرشحو الاسم يحوون `id` و`full_name` و`role` و`department` فقط.

للتكامل الآمن: اعرض جميع التحذيرات والأخطاء والصفوف الخام، ولا تقبل `needs_review` قبل التصحيح والتحقق مجددًا من كل الحقول والمستخدم النشط والدور. لا يكفي تعديل `status` أو اختيار `candidate` وحده. أعِد التحقق من الصلاحية وهوية المستخدم عند التأكيد، وافحص التكرارات مقارنةً بـ`DATA.shifts` أيضًا؛ فالمكوّن يكشف التكرار داخل الملف فقط. بعد موافقة صريحة وصلاحيات مناسبة، يستطيع التطبيق استدعاء مسار حفظه الخاص بصفوف مؤكدة، ولا يربط هذا المكوّن نفسه بأية دوال حفظ أو تدقيق.

## التنسيق المدعوم

- جداول مسطّحة مع صف عناوين يضم التاريخ والفترة وأحد اسم المستخدم أو معرّفه أو رقمه الوظيفي؛ يسمح بنصوص فوق العناوين وبتكرار العناوين. أمثلة: `التاريخ,الفترة,الرقم الوظيفي,الدور,ملاحظات` أو `Date,Shift,Name,Role,Notes`. يمكن استخدام `User ID` لمعرّف التطبيق و`Employee ID` أو `Username` لاسم الدخول/الرقم الوظيفي. الأسماء تطابق `full_name` تطابقًا كاملًا بعد تطبيع محافظ، وليس بالتشابه أو الاسم الجزئي. إذا تكرر الاسم يُترك الربط ملتبسًا حتى يختار المستخدم؛ المعرف المجهول لا يرجع للمطابقة بالاسم. يُستبعد غير النشط والمعلّق والمرفوض كما في التطبيق. عند وجود دور مخالف لدور الحساب يتطلب الصف مراجعة.
- الفترة `صباحي` و`مسائي` و`ليلي` وبعض مرادفاتها العربية والإنجليزية، ومنها Morning وEvening وNight. دور المناوبة اختياري في المصدر ويُشتق من الحساب عند غيابه.
- التواريخ الميلادية العربية والإنجليزية تشمل أرقام `٠١٢٣` و`۰۱۲۳`، وأسماء الأشهر، وISO. تاريخ مثل `03/04/2026` يظهر ملتبسًا ولا يُخمّن ترتيبه؛ يُفضّل ISO. لا تحويل تلقائي للتقويم الهجري ولا قبول للسنة ذات الرقمين. خلايا تاريخ Excel الرقمية يجب أن تكون منسّقة كتاريخ؛ ويؤخذ نظام 1900 أو 1904 من المصنف. الصيغ تتطلب مراجعة لأن قيمها المخزّنة قد تكون قديمة؛ لا يحسب المكوّن الصيغ.
- `CSV` بترميز UTF-8، والفاصل فاصلة أو فاصلة منقوطة أو جدولة أو فاصلة منقوطة عربية. يُستنتج الفاصل من أول سجل؛ اقتبس الحقول المحتوية عليه أو على أسطر جديدة. `XLSX` و`XLS` تُعالَج فيهما الأوراق وتُحذّر الأوراق غير المعنونة.
- `PDF` النصي ذو جدول منتظم وعناوين في كل صفحة؛ تُقدّر الأعمدة من مواضع طبقة النص، ولذلك يجب مراجعة **كل خلية مقابل الأصل** حتى لو كان الصف `ready`. الاتجاهات المختلطة والأعمدة المدمجة أو غير المنتظمة أو المتداخلة والخطوط والنصوص المفككة قد تفشل أو تُستخرج بترتيب غير متوقع؛ تظهر تنبيهات، ولا تُضمن إعادة بناء كل تخطيط. لا توجد OCR ولا دعم لملف مصوّر بلا طبقة نص.

الحدود: 15 MiB للملف، و20 ألف صف بيانات، و100 عمود، و200 صفحة PDF، و100 ألف عنصر نصي في صفحة PDF. هذه حدود تشغيلية وليست حماية كاملة من الملفات الضارة أو مضخمات ZIP؛ تحليل Excel يحدث على مؤشر المتصفح الرئيسي وقد يستهلك موارد. استخدم ملفات موثوقة وحدّث المكتبات دوريًا.

## المكتبات والرخص

نسخ محلية من توزيعات أصلية مفتوحة المصدر، الرخص بجانبها:

- SheetJS Community Edition 0.20.3، رخصة Apache-2.0: `vendor/xlsx.full.min.js` و`vendor/SHEETJS-LICENSE` من الحزمة الرسمية [xlsx-0.20.3.tgz](https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz). بصمة SHA-256 للحزمة: `8dc73fc3b00203e72d176e85b50938627c7b086e607c682e8d3c22c02bb99fe8`. لا تستخدم `xlsx` القديم من npm بدلًا من النسخة الرسمية.
- Mozilla PDF.js `pdfjs-dist` 4.10.38، رخصة Apache-2.0: `vendor/pdf.min.mjs` و`vendor/pdf.worker.min.mjs` و`vendor/PDFJS-LICENSE` من [حزمة npm الأصلية](https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-4.10.38.tgz). بصمة SHA-256 للحزمة: `1011b38553532d7078c59f26b15a471f8dae00f101b60e2add9b8511737a1ce0`. عطّلنا eval ودعم XFA في إعدادات PDF.js. راجع تحديثات الأمان عند إدماج المكوّن.

يمكن إعادة استخراج الملفات من المسارين `package/dist/xlsx.full.min.js` و`package/LICENSE` في الحزمة الأولى، و`package/legacy/build/pdf.min.mjs` و`package/legacy/build/pdf.worker.min.mjs` و`package/LICENSE` في الثانية. لا يتطلب هذا تعديل `package.json`.

## الاختبار

من جذر المشروع:

```sh
node --test tests/shift-import/import.test.cjs
python3 tests/shift-import/browser_test.py
```

الأول ينشئ XLSX وXLS حقيقيين ويفحص التواريخ والالتباس والتكرار والصيغ والملفات غير الصالحة. الثاني يحتاج Python Playwright وReportLab وChromium في `/usr/bin/chromium`؛ ينشئ PDFs نصية عربية وإنجليزية وأخرى بلا نص، ويشغّل خادمًا محليًا مؤقتًا ويمنع طلبات الشبكة الخارجية.
